DAYFLOW — first working web-app build

Included:
- Daily task list with categories and completion
- Custom daily habits
- Water tracker (8 glasses)
- Progress totals and active-day count
- Local browser storage (data stays on this device/browser)
- JSON backup export/import
- PWA manifest + service worker for install/offline use after HTTPS hosting

IMPORTANT:
This is a working web app, not an Android APK. To install it like an app, it must be hosted at an HTTPS address. Open that address in Chrome on Android, tap the three-dot menu, then choose “Install app” or “Add to Home screen”.

For a quick preview, open index.html in a browser. Browser restrictions mean install/offline features may not work when opened as a local file.

Data note: clearing browser/site data can erase the local data. Use Export backup periodically. Data does not sync between devices in this version.
